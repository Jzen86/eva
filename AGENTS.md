# Betsy — зона проекта

Зона проекта — Telegram-AI-компаньон **«Betsy»**: живёт в **личке владельца** как персонаж с памятью, голосом и медиа. Крутится на сервере `rdp-fi` (Node.js, канал Telegram через grammy, LLM через OpenRouter, память SQLite).

**Источник истины и инструкция — `BOT.md` в этой папке.** Читать целиком перед любой работой с Бетси.

Правила:
- Правишь Бетси → в том же цикле обнови `BOT.md`.
- Секреты (токен Telegram-бота, ключ OpenRouter) не выводить никуда и не хранить здесь — только имена переменных/полей конфига.
- **Задрота (`D:\TG\zadrot\`) НЕ трогать** — это отдельная сущность на том же сервере, со своим сервисом и базой. Правки Бетси не должны касаться задрота (и наоборот).
- Не путать Бетси с **ПУ-ботом** (корневой проект `D:\TG\AGENTS.md` — мост к OpenCode, сервер `:4096`): это три разных бота.
- Доп. контекст инфраструктуры (при надобности): корневой `D:\TG\AGENTS.md`.
